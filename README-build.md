# Сборка «Собеседника» для этого ноутбука

Это приложение Rust/Tauri с локальным распознаванием речи. Захват звука, выделение фраз, контекст и подключения моделей выполняются в Rust. **Python используется только как отдельный процесс вычислений Whisper на видеокарте.**

`Build.ps1` собирает папку запуска. `Build.ps1 -Installer` собирает установщик Windows x64 для текущего пользователя.

## Установщик Windows

```powershell
.\Build.ps1 -Installer
```

Готовый файл — `installer-dist\Sobesednik-0.2.1-x64-setup.exe`. Для первой сборки нужны интернет для загрузки NSIS и подписанный Google клиент `vendor\agy.exe`. Установщик содержит приложение, модуль Whisper и `agy.exe`. При отсутствии WebView2 мастер установки скачивает его.

Перед установкой закройте открытый «Собеседник». После установки запускайте его из меню «Пуск». Приложение использует прежнюю папку `%APPDATA%\local.sobesednik.desktop` с комнатами и настройками. При удалении программы оставьте выключенной опцию удаления данных приложения, чтобы сохранить историю.

На другом компьютере для распознавания речи отдельно понадобятся компоненты из списка ниже. Пакет не включает ваши настройки или данные входа.

## Что требуется

Для сборки:

- Rust с инструментами MSVC в `%USERPROFILE%\.cargo\bin`.
- Microsoft C++ Build Tools и Windows SDK.
- Node.js и npm, доступные из PowerShell.
- Интернет для первого получения зависимостей npm и Cargo.

Для работы на текущем ноутбуке:

- Windows и WebView2.
- Настроенный Python **3.14** с `faster-whisper`, CTranslate2, NumPy и зависимостями распознавания. Сейчас используется `C:\Python314\python.exe`.
- Модель Whisper `small` в локальном кэше. Приложение загружает её с `local_files_only=True`; модель не скачивается автоматически при запуске.
- Рабочие библиотеки NVIDIA cuBLAS/cuDNN из подготовленного каталога `identityproxy-feasibility-check\whisper\cuda-libs` и драйвер видеокарты. Эти библиотеки не входят в папку результата сборки.
- Для Antigravity — официальный CLI и вход, выполненный самим официальным клиентом. Для ChatGPT — вход через подписку и проверенное ограничение расходов приложения.
- Для Claude — установленный официальный Claude Code, вход по личной подписке и отключённый Extra usage. Клиент Claude не входит в папку сборки, по умолчанию используется `%USERPROFILE%\.local\bin\claude.exe`.

Пути локальных компонентов можно проверить в настройках приложения. Публичные идентификаторы прежней регистрации ChatGPT приложение переносит при первом запуске из соседней папки проверки, если она доступна. Токены авторизации сборщик не копирует.

## Команда сборки

Закройте ранее запущенный `Sobesednik.exe`, чтобы Windows позволила обновить этот файл. В PowerShell выполните:

```powershell
cd D:\projects\voice-assistant-rust
.\Build.ps1
```

Скрипт:

1. Временно добавляет пользовательский `.cargo\bin` в `PATH` текущего процесса.
2. Выполняет `npm ci`, только если `node_modules` отсутствует.
3. Запускает `npm run tauri -- build --no-bundle`. Tauri также собирает интерфейс через настроенный `beforeBuildCommand`.
4. Проверяет коды завершения и наличие собранного EXE.
5. Обновляет только перечисленные ниже файлы в `desktop-dist`. Остальные файлы и каталоги не удаляет.
6. Восстанавливает прежние значения `PATH` и `CARGO_TARGET_DIR` текущего процесса.

`CARGO_TARGET_DIR` на время команды указывает на `src-tauri\target`, чтобы в папку запуска попадал результат именно этой сборки. Глобальные переменные среды и системные настройки не меняются.

## Результат

```text
desktop-dist/
  Sobesednik.exe
  resources/
    whisper_worker.py
  vendor/
    agy.exe
```

`agy.exe` копируется из `vendor\agy.exe` в папке проекта. Если файла нет, сборка папки запуска завершится с предупреждением, а для сборки установщика потребуется добавить клиент. Скрипт не скачивает Antigravity.

Запуск приложения выполняется вручную:

```powershell
.\desktop-dist\Sobesednik.exe
```

Сборка не запускает приложение, не включает микрофон и не отправляет запросы моделям. Непрерывное слушание в самом приложении включается пользователем и не запускает автоматические ответы.

## Проверки без полной сборки

```powershell
npm run build
node --test src/ui-state.test.mjs
cargo test --manifest-path src-tauri\Cargo.toml
```

Запуск этих команд проверяет код и интерфейс. Работу реальных аудиоустройств, входов в подписки и внешних моделей нужно проверять отдельно в приложении.
