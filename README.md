# While We Talk

*Live notes. Answers when you ask.*

While We Talk расшифровывает речь с микрофона и звук компьютера. У каждого разговора своя комната с историей, заметками, ответами и итогом. Whisper обрабатывает звук на компьютере. Текст отправляется выбранной модели, когда ты нажимаешь «Получить ответ» или «Подвести итог».

**[Скачать установщик для Windows x64](https://github.com/Cartmanidze/while-we-talk/releases/latest)**

Раньше приложение называлось «Собеседник». Для перехода закрой старую версию, установи While We Talk и открой его из меню «Пуск». Обе версии используют одну папку с историей и настройками. Если решишь удалить старую версию через настройки Windows, оставь флажок удаления данных приложения снятым.

## Первый разговор

1. Открой While We Talk из меню «Пуск» и нажми «Создать комнату».
2. В настройках выбери микрофон, звук компьютера или оба источника. Нажми «Начать расшифровку». После паузы фраза появится в истории разговора.
3. Чтобы добавить вопрос текстом, введи его в поле и нажми «Сохранить реплику». Во время расшифровки можно набрать черновик и сохранить его после остановки.
4. Когда понадобится ответ, открой «Настройки → Подключения», выбери сервис и модель. Вернись в комнату и нажми «Получить ответ».
5. Чтобы собрать решения и открытые вопросы, останови расшифровку и нажми «Подвести итог» на вкладке «Итог».

## Подключения

Можно одновременно подключить ChatGPT, Antigravity и Claude Code. Для каждого сервиса запоминается последняя выбранная модель. Ответы и итоги расходуют квоту её подписки.

- **ChatGPT.** Для входа нужна регистрация приложения. В настройках аккаунта проверь лимит 30% и отключи платные кредиты. Подтверждение этих условий в While We Talk сохраняет твой выбор. После перезапуска потребуется войти снова.
- **Antigravity.** Войди в официальном приложении и нажми «Проверить вход» в While We Talk. Список моделей приходит из клиента Antigravity.
- **Claude Code.** Нужны установленный Claude Code и личная подписка Claude. Перед первым запросом отключи Extra usage в аккаунте. Если клиент не вернул каталог, в списке появятся стандартные имена моделей. Их доступность зависит от аккаунта.

## Что сохраняется

Комнаты, расшифровки и настройки хранятся в `%APPDATA%\local.sobesednik.desktop`. Название комнаты появляется по первой содержательной реплике. Его можно изменить. Поиск находит слова в том числе в старых репликах. Чтобы скопировать разговор в Markdown, нажми кнопку копирования рядом с названием.

Удалённую комнату можно восстановить из корзины вместе с историей и итогом. Если файл комнаты повреждён, приложение предложит доступную резервную копию. Длинный разговор хранится целиком. Когда он перестаёт помещаться в запрос модели, приложение готовит краткое содержание ранних реплик. Исходные записи остаются в комнате.

## Горячие клавиши

| Сочетание | Действие |
| --- | --- |
| Ctrl+Alt+M | Показать окно и открыть настройки |
| Ctrl+Alt+N | Создать комнату |
| Ctrl+Enter в поле ввода | Сохранить реплику |
| Ctrl+Enter вне поля ввода | Получить ответ |

Сочетания работают, пока приложение запущено. В настройках окна можно выбрать непрозрачность от 30 до 100% и скрытие при демонстрации экрана. Результат зависит от программы записи.

## Установка и разработка

Настольное приложение написано на Rust и Tauri, интерфейс — на React и TypeScript. Распознавание выполняет отдельный процесс Python с Whisper на видеокарте NVIDIA. Для нового компьютера нужно подготовить Python, модель Whisper и библиотеки CUDA. [Требования и команды сборки](README-build.md).

Для проверки интерфейса запусти `node --test src/*.test.mjs`. Для браузерных сценариев запусти `npm run dev -- --port 1421`, затем в папке `tools/browser-check` выполни `npm ci` и `npm test`. Понадобится Chrome. Эти проверки работают на тестовых разговорах. Для проверки Rust выполни `cargo test --manifest-path src-tauri/Cargo.toml --lib`.
